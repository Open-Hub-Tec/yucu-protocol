# Traceability matrix for Yucu rules

This matrix connects the nine rules in [AGENTS.md](../../AGENTS.md#reglas-que-no-se-rompen) to their architecture decisions, files present in `main`, and existing assertions in `src/tests/`. It helps contributors locate evidence and outstanding work for each rule. The [README implementation status table](../../README.md#implementation-status) complements this review.

**Partial** coverage checks only the behavior described in the cell. **No test yet** means that a specific test is missing from `src/tests/` for the rule or the identified part. CI validators and ESLint checks are identified separately because they live outside that directory.

## Rules without specific tests in src/tests

- **Rule 4** — exclusive UI dependency on its ports.
- **Rule 5** — exclusion of personal data, forbidden fields, and audio deletion.
- **Rule 6** — environment handling and absence of secrets from code, tests, and logs.
- **Rule 8** — correspondence between published claims and their evidence.
- **Rule 9** — manifest-guided extraction with human confirmation and signing, plus audio and AI provider restrictions.

## Outstanding parts of rules with partial coverage

- **Rule 1** — absence of server custody and effective erasure of QR-card keys.
- **Rule 2** — real Trustless Work adapter and Attest Protocol attestations.
- **Rule 3** — visible simulation label and detection of invented results outside `SimulatedChain.ts`.
- **Rule 7** — comparison with the teaching `fair_escrow` constant, which is outside the app, and detection of duplicated values expressed with other wording.

## Reproducing the search

Run these searches from the repository root to locate the assertions, then read the complete test files and their implementations to determine the actual coverage scope.

```bash
rg --files src/tests
rg -n 'prepareRegisterLot|wallet.sign|card.sign|wrongPin|wrongNetwork' src/tests
rg -n 'SimulatedEscrow|TrustlessWorkEscrowAdapter|Attest|AttestationPort' src/tests
rg -n 'source|explorerUrl|DemoBadge' src/tests
rg -n 'protocolFees|calculateSecondaryRoyalty|producerRoyalty|tequioFund' src/tests
rg -n -i 'manifest|manifiesto|forbidden|privacidad|privacy|secret|GEMINI_API_KEY|no-restricted-imports' src/tests
```
